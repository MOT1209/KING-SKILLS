# formal-messages — formal business messages

> English translation of [README.md](README.md).

## What the skill does
Writes ready-to-send business messages in a suitable tone: follow-up, apology, request, reminder, thanks, or polite refusal, in Arabic or English.

## When to use it
- You need a professional message and do not know how to start.
- You have a draft and want it more formal and clear.

## Example requests
1. "Write a follow-up message to a project manager who has not replied to my proposal for a week, in a polite tone."
2. "Write a formal apology to a client for delivering two days late, saying I will send the files tomorrow."
3. "Rewrite this message to be more formal and shorter: [paste message]"

## What to expect
| Item | What you get |
|---|---|
| Structure | Subject line, greeting, a concise body, a clear request, a signature |
| Placeholders | Such as [Recipient name]; you replace them before sending |
| Alternatives | A shorter or warmer version on request |
| Limits | No promises or facts that you did not state |
