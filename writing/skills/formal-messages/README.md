# formal-messages — رسائل العمل الرسمية

## ما الذي تفعله المهارة
تكتب لك رسائل عمل جاهزة بنبرة مناسبة: متابعة، اعتذار، طلب، تذكير، شكر، أو رفض مهذب، بالعربية أو الإنجليزية.

## متى تستخدمها
- تريد رسالة مهنية ولا تعرف كيف تبدؤها.
- عندك مسوّدة وتريدها أكثر رسمية ووضوحاً.

## أمثلة على الطلبات
1. «اكتب رسالة متابعة لمدير مشروع لم يرد على عرضي منذ أسبوع، بنبرة مهذبة.»
2. «اكتب اعتذاراً رسمياً لعميل عن تأخر التسليم يومين، مع ذكر أنني سأرسل الملفات غداً.»
3. «أعد صياغة هذه الرسالة لتكون أكثر رسمية وأقصر: [الصق الرسالة]»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| البنية | سطر موضوع، تحية، نص موجز، طلب واضح، توقيع |
| العناصر النائبة | مثل [اسم المستلم]؛ تستبدلها قبل الإرسال |
| البدائل | نسخة أقصر أو أودّ عند الطلب |
| الحدود | لا وعود أو وقائع لم تذكرها أنت |
