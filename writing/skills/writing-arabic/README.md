# writing-arabic — الكتابة العربية

## ما الذي تفعله المهارة
تساعدك على كتابة محتوى عربي جديد (مقالات، رسائل، منشورات) أو تحرير نص موجود، مع تدقيق لغوي (إملاء ونحو وترقيم) وتحسين الأسلوب والوضوح.

## متى تستخدمها
- عندك فكرة وتريدها مقالاً أو منشوراً جاهزاً.
- عندك مسوّدة وتريد تلميعها وتصحيحها.
- تريد رسالة رسمية أو مهنية بنبرة مناسبة.

## أمثلة على الطلبات
1. «اكتب لي منشوراً قصيراً للتواصل الاجتماعي عن أهمية القراءة اليومية، بنبرة ودّية، في حدود 80 كلمة.»
2. «دقّق هذا النص لغوياً وحسّن أسلوبه مع الحفاظ على معناه، ثم أخبرني بأهم التعديلات: [الصق النص]»
3. «اختصر هذه الفقرة إلى النصف دون أن تفقد فكرتها الرئيسة: [الصق الفقرة]»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الكتابة الجديدة | نص عربي سليم بنبرة وطول مناسبين |
| التحرير | النص المصحَّح مع قائمة موجزة بالتعديلات وأسبابها |
| الناقص | معلومة غير متوفرة تُعلَّم [يُستكمل] |
| الحدود | لا أرقام ولا اقتباسات ولا مصادر مختلقة |
