# translation-arabic-english — الترجمة عربي ⇄ إنجليزي

## ما الذي تفعله المهارة
تترجم النصوص بين العربية والإنجليزية بدقة وطبيعية، وتوحّد المصطلحات المتكررة، وتحافظ على نبرة الأصل وتنسيقه.

## متى تستخدمها
- تترجم مقالاً أو عقداً أو عرضاً تسويقياً أو رسالة.
- عندك ترجمة وتريد مراجعتها.
- تريد ثبات المصطلحات عبر مستند طويل.

## أمثلة على الطلبات
1. «ترجم هذه الفقرة التسويقية إلى العربية بنبرة حماسية وبدون ترجمة حرفية: [النص]»
2. «ترجم هذا التقرير التقني إلى الإنجليزية، واستخدم المسرد التالي للمصطلحات: [المسرد]»
3. «راجع ترجمتي الإنجليزية لهذه الرسالة وأخبرني بما يبدو غير طبيعي: [النص الأصلي] [ترجمتي]»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الترجمة | وفية للمعنى وبتنسيق الأصل |
| الملاحظات | شرح الألفاظ الملتبسة وبدائلها |
| المصطلحات | جدول موحّد للنصوص الطويلة |
| القانوني والطبي | تنبيه إلى مراجعة مترجم معتمد |
