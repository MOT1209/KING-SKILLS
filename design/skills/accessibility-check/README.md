# accessibility-check — فحص إمكانية الوصول

## ما الذي تفعله المهارة
تفحص تصميمك أو صفحتك مقابل معايير WCAG 2.2 AA: التباين، الأهداف اللمسية، النصوص البديلة، التنقل بلوحة المفاتيح، وعدم الاعتماد على اللون وحده.

## متى تستخدمها
- قبل التسليم أو الإطلاق.
- عند تصميم مكوّن تفاعلي جديد (نموذج، قائمة، نافذة).

## أمثلة على الطلبات
1. «افحص هذا النموذج (كود HTML مرفق) وفق WCAG 2.2 AA وأعطني قائمة بالإصلاحات.»
2. «ألوان أزرار تطبيقي: [القيم]. هل التباين كافٍ، وهل الأزرار بحجم مناسب للمس؟»
3. «افحص صفحة الدخول عندي: [الكود]، وركّز على لوحة المفاتيح ورسائل الخطأ.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| النتائج | جدول: الفحص، المعيار، النتيجة، الدليل، الإصلاح |
| النطاق | ما فُحص وما لم يُفحص |
| التباين | نسب محسوبة لا مقدَّرة |
| الحدود | لا يغني عن اختبار المستخدمين، وليس استشارة قانونية |
