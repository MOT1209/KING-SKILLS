# icon-set — icon set

> English translation of [README.md](README.md).

## What the skill does
Unifies your icons with a fixed stroke width and drawing grid, and defines for each icon its states: default, active, disabled, and others.

## When to use it
- Your app's icons look like they come from several sources.
- You are building a design system and need rules for icons.

## Example requests
1. "Define the specifications of an icon set for a delivery app: 24 icons, outline, with states."
2. "I have icons with different stroke widths, show me how to unify them and which of them mirror in RTL."
3. "Define the states of the bottom navigation bar icons (default, active, disabled) with attention to contrast."

## What to expect
| Item | What you get |
|---|---|
| Specifications | A fixed grid, stroke, style and corners |
| States | Default, active and disabled with color and contrast |
| Naming | Fixed rules with start/end for directional ones |
| SVG | Clean on request, with a license warning |
