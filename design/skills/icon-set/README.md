# icon-set — مجموعة الأيقونات

## ما الذي تفعله المهارة
توحّد أيقوناتك بسماكة خط وشبكة رسم ثابتتين، وتحدد لكل أيقونة حالاتها: عادية، نشطة، معطلة، وغيرها.

## متى تستخدمها
- أيقونات تطبيقك تبدو كأنها من مصادر متعددة.
- تبني نظام تصميم وتحتاج قواعد للأيقونات.

## أمثلة على الطلبات
1. «حدّد مواصفات مجموعة أيقونات لتطبيق توصيل: 24 أيقونة، خطية، مع الحالات.»
2. «عندي أيقونات بسماكات مختلفة، وضّح لي كيف أوحّدها وأي منها يُعكس في RTL.»
3. «حدّد حالات أيقونات شريط التنقل السفلي (عادية، نشطة، معطلة) مع مراعاة التباين.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| المواصفات | شبكة وسماكة وأسلوب وزوايا ثابتة |
| الحالات | عادية ونشطة ومعطلة بلون وتباين |
| التسمية | قواعد ثابتة مع start/end للاتجاهية |
| SVG | نظيف عند الطلب، مع تنبيه للرخصة |
