# typography-pairing — font pairing

> English translation of [README.md](README.md).

## What the skill does
Chooses a matching Arabic font and Latin font for you, and defines the scale of sizes, weights and line height for each text element.

## When to use it
- Your website, app or identity is bilingual.
- Your Arabic text looks larger or heavier than the Latin (or the reverse).

## Example requests
1. "Choose me a pairing between an Arabic and a Latin font for a consulting company website, with a size table."
2. "My app uses Inter, which Arabic font suits it and how do I set the line height?"
3. "The Arabic text on my site looks smaller than the English, how do I adjust the size and line height?"

## What to expect
| Item | What you get |
|---|---|
| The pairing | An Arabic font and a Latin font with the reason |
| The scale | Sizes, weights and line height for each role |
| Setup | Fallback fonts and the loading method |
| Limits | Starting values to adjust on your text, and a license check |
