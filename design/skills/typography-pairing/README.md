# typography-pairing — اقتران الخطوط

## ما الذي تفعله المهارة
تختار لك خطاً عربياً وآخر لاتينياً متناسقين، وتحدد سلّم المقاسات والأوزان وارتفاع السطر لكل عنصر نصي.

## متى تستخدمها
- موقعك أو تطبيقك أو هويتك ثنائية اللغة.
- نصك العربي يبدو أكبر أو أثقل من اللاتيني (أو العكس).

## أمثلة على الطلبات
1. «اختر لي اقتراناً بين خط عربي ولاتيني لموقع شركة استشارات، مع جدول المقاسات.»
2. «تطبيقي يستخدم Inter، أي خط عربي يناسبه وكيف أضبط ارتفاع السطر؟»
3. «نصوص موقعي العربية تبدو أصغر من الإنجليزية، كيف أضبط الحجم وارتفاع السطر؟»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الاقتران | خط عربي وآخر لاتيني مع السبب |
| السلّم | مقاسات وأوزان وارتفاع السطر لكل دور |
| الإعداد | خطوط بديلة وطريقة التحميل |
| الحدود | قيم بدء تُضبط على نصك، وتحقق من الترخيص |
