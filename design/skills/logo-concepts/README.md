# logo-concepts — اتجاهات الشعار

## ما الذي تفعله المهارة
تقترح ثلاثة اتجاهات بصرية متمايزة لشعارك، وتشرح لكل اتجاه لماذا يناسب اسم علامتك وقيمها وكيف يعمل بالعربية والإنجليزية.

## متى تستخدمها
- في بداية تصميم الشعار قبل التفاصيل.
- عندما تتردد بين شعار كتابي ورمز.

## أمثلة على الطلبات
1. «علامة اسمها «سَنَد» لخدمات الدعم النفسي، قيمها: الأمان والدفء والخصوصية. أعطني ثلاثة اتجاهات للشعار.»
2. «شركة Nova Logistics ولها اسم عربي «نوفا للشحن». اقترح اتجاهات شعار تعمل بالعربية واللاتينية.»
3. «أعدت تسمية شركتي، وأريد معرفة هل أبقى على الشعار الكتابي أم أنتقل إلى رمز. قارن لي بين الاتجاهات.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الاتجاهات | ثلاثة اتجاهات متمايزة، لكل منها الوصف والسبب والاستخدام |
| اللغتان | طريقة ترتيب الاسم العربي واللاتيني |
| الاختبارات | تصغير، لون واحد، خلفيات فاتحة وداكنة |
| الحدود | ليست ملفات نهائية ولا ضماناً بالتفرد أو التسجيل |
