# design-handoff — تسليم التصميم

## ما الذي تفعله المهارة
توثّق تصميمك للمطورين بقيم دقيقة للمقاسات والمسافات والألوان والخطوط، مع أسماء ثابتة للمكونات وحالات التفاعل.

## متى تستخدمها
- قبل أن يبدأ المطوّر بالتنفيذ.
- حين يختلف الناتج عن التصميم وتريد مرجعاً واضحاً.

## أمثلة على الطلبات
1. «وثّق زر التطبيق الرئيس: المقاسات والمسافات والألوان وكل حالاته. هذه مواصفات التصميم: [القيم]»
2. «حوّل لوحة الألوان وسلّم الخطوط عندي إلى Design Tokens بصيغة JSON.»
3. «اكتب قائمة تحقق لمراجعة المطوّر لشاشة التسجيل قبل إغلاق المهمة.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الرموز | جدول أو JSON بالأسماء والقيم |
| المكونات | مقاسات ومسافات وحالات كاملة |
| RTL والأصول | ملاحظات الانعكاس وصيغ الأصول |
| الحدود | كل رقم من تصميمك، والنقص [يُستكمل] |
