# ui-layout — تخطيط الواجهة

## ما الذي تفعله المهارة
تنظّم شاشتك بشبكة ثابتة ومسافات متناسقة، وترتب الأزرار حسب الأولوية، وتضمن عمل التخطيط باتجاه RTL.

## متى تستخدمها
- شاشة مزدحمة لا يعرف المستخدم من أين يبدأ فيها.
- واجهة إنجليزية تريد نقلها إلى العربية.

## أمثلة على الطلبات
1. «صمّم تخطيط شاشة الدفع في تطبيق جوال بالعربية، مع ترتيب الأزرار.»
2. «لوحة التحكم عندي مصممة LTR، حوّلها إلى RTL وأخبرني ما الأيقونات التي تنعكس.»
3. «شاشة الإعدادات عندي طويلة ومزدحمة، أعد ترتيبها بأولويات واضحة.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الشبكة | أعمدة وفواصل وهوامش ووحدة مسافة |
| المخطط | نصي أو HTML/CSS بسيط |
| الأزرار | ترتيب مبرَّر بالأولوية |
| RTL | قائمة بما ينعكس وما لا ينعكس |
