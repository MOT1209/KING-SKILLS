# ui-layout — interface layout

> English translation of [README.md](README.md).

## What the skill does
Organizes your screen with a fixed grid and consistent spacing, orders the buttons by priority, and makes sure the layout works in RTL.

## When to use it
- A crowded screen where the user does not know where to start.
- An English interface you want to move to Arabic.

## Example requests
1. "Design the layout of the payment screen in a mobile app in Arabic, with the button order."
2. "My dashboard is designed LTR, convert it to RTL and tell me which icons mirror."
3. "My settings screen is long and crowded, rearrange it with clear priorities."

## What to expect
| Item | What you get |
|---|---|
| The grid | Columns, gutters, margins and a spacing unit |
| The diagram | Textual or simple HTML/CSS |
| Buttons | An order justified by priority |
| RTL | A list of what mirrors and what does not |
