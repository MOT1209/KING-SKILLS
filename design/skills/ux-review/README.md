# ux-review — مراجعة تجربة المستخدم

## ما الذي تفعله المهارة
تتبع مهمة المستخدم خطوة بخطوة، وتحدد أين يتردد أو يلتبس عليه، وترتب الملاحظات حسب الأثر مع تعديل مقترح لكل نقطة.

## متى تستخدمها
- ترى مستخدمين يتركون التدفق في منتصفه.
- قبل إطلاق نسخة جديدة من تدفق مهم.

## أمثلة على الطلبات
1. «راجع تدفق التسجيل في تطبيقي (لقطات الشاشة مرفقة) من فتح التطبيق حتى تأكيد البريد.»
2. «لماذا يتصل العملاء بالدعم بعد حجز الموعد؟ هذه خطوات الحجز: [الوصف]»
3. «يترك المستخدمون نموذج الاشتراك عند حقل البطاقة، راجع النموذج وأخبرني بالأسباب المحتملة.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| التتبع | الخطوات ونقاط التردد والالتباس |
| الملاحظات | مرتبة بالأثر مع تعديل وطريقة تحقق |
| ما يعمل | قائمة بالجيد |
| الحدود | حكم خبير لا قياس، ولا أرقام مختلقة |
