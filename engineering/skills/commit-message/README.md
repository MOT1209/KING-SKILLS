# commit-message — رسائل Commit

## ما الذي تفعله المهارة
تكتب رسائل commit بصيغة Conventional Commits مختصرة وواضحة، وتوسم التغييرات الكاسرة، وتقترح تقسيم التغييرات المختلطة.

## متى تستخدمها
- تكتب رسالة لتغيير جاهز.
- رسائلك القديمة غامضة مثل «fix stuff».

## أمثلة على الطلبات
1. «اكتب رسالة commit للتغييرات المرحلة (staged).»
2. «هذه رسائلي: "fix stuff"، "update"، "wip". أعد صياغتها بحسب ما تغيّر فعلاً.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الرسالة | type(scope): description وجسم عند الحاجة |
| الكاسر | وسم صريح مع الأثر وطريقة الترحيل |
| الحدود | لا وصف لما لم يتغير؛ التغيير المختلط يُقترح تقسيمه |
