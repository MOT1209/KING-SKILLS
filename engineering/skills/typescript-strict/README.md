# typescript-strict — TypeScript صارم

## ما الذي تفعله المهارة
تكتب أو تصلح TypeScript بأنواع صارمة: تستبدل `any` بـ `unknown` مع تضييق آمن، وتستعمل الأنواع المشتقة والاتحادات المميَّزة.

## متى تستخدمها
- تحوّل ملف JavaScript إلى TypeScript.
- مشروعك مليء بـ any و as وتريد تشديده تدريجياً.

## أمثلة على الطلبات
1. «حوّل هذا الملف من JavaScript إلى TypeScript صارم: [الملف]»
2. «افحص مشروعي بحثاً عن `any` و`as` الخطرة واقترح بدائل مرتبة بالأولوية.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الكود | أنواع صارمة وحراس نوع وأنواع مشتقة |
| الملخص | ما استُبدل ولماذا ونتيجة tsc --noEmit |
| الحدود | لا إسكات للأخطاء بـ any أو @ts-ignore |
