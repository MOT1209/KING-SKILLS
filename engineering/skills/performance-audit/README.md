# performance-audit — تدقيق الأداء

## ما الذي تفعله المهارة
تحلّل سبب البطء بالقياس، وتجرّب تحسينات واحداً واحداً، وتقارن قبل وبعد بالطريقة نفسها.

## متى تستخدمها
- نقطة API أو صفحة أو استعلام بطيء.
- تريد التأكد أن تحسيناً فعلاً حسّن الأداء.

## أمثلة على الطلبات
1. «استعلام التقارير يأخذ وقتاً طويلاً، هذا الاستعلام وخطة EXPLAIN: [الصق]. ما السبب؟»
2. «صفحة قائمة المنتجات بطيئة في الواجهة، حلّل وأخبرني أين عنق الزجاجة.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| التشخيص | عنق الزجاجة بدليل مقيس |
| القياسات | جدول قبل/بعد تملؤه قياساتك الفعلية |
| الحدود | لا أرقام مختلقة ولا تحسين دون قياس |
