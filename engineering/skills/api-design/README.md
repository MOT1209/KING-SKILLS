# api-design — تصميم واجهات API

## ما الذي تفعله المهارة
تصمّم نقاط REST أو GraphQL بتسمية متسقة، وصيغة أخطاء موحّدة، واستراتيجية إصدار واضحة.

## متى تستخدمها
- تبدأ واجهة جديدة أو توسّع واجهة قائمة.
- واجهتك تضخمت بلا قواعد تسمية موحدة.

## أمثلة على الطلبات
1. «صمّم REST API لنظام حجز مواعيد: عيادات، أطباء، مواعيد.»
2. «راجع هذه المسارات وأخبرني أين التناقض في التسمية والأخطاء: [القائمة]»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الجدول | النقاط والطرق والحالات الناجحة والأخطاء |
| الأمثلة | طلب واستجابة وخطأ بصيغة ثابتة |
| الحدود | لا أسرار في الأمثلة؛ القرارات المفتوحة مذكورة |
