# api-design — API design

> English translation of [README.md](README.md).

## What the skill does
Designs REST or GraphQL endpoints with consistent naming, a unified error format, and a clear versioning strategy.

## When to use it
- You are starting a new API or extending an existing one.
- Your API grew without unified naming rules.

## Example requests
1. "Design a REST API for an appointment booking system: clinics, doctors, appointments."
2. "Review these paths and tell me where the naming and errors are inconsistent: [list]"

## What to expect
| Item | What you get |
|---|---|
| The table | The endpoints, methods, success statuses and errors |
| Examples | A request, a response and an error in a fixed format |
| Limits | No secrets in the examples; open decisions are stated |
