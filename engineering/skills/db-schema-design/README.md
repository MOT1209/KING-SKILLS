# db-schema-design — تصميم مخطط قاعدة البيانات

## ما الذي تفعله المهارة
تصمّم الجداول والعلاقات والفهارس، وتراجع التطبيع، وتكتب خطة ترحيل آمنة قابلة للتراجع.

## متى تستخدمها
- تصمّم جداول لميزة جديدة.
- تحتاج ترحيلاً آمناً على جدول يحوي بيانات.

## أمثلة على الطلبات
1. «صمّم مخطط PostgreSQL لتطبيق مهام: مستخدمون ومشاريع ومهام وتعليقات.»
2. «أريد تقسيم عمود العنوان في جدول العملاء إلى حقول، اكتب خطة ترحيل بدون توقف.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| المخطط | SQL وعلاقات وقيود |
| الفهارس | جدول يربط كل فهرس بالاستعلام الذي يخدمه |
| الترحيل | خطوات صغيرة وخطة تراجع؛ لا تنفيذ على قاعدة حقيقية دون طلبك |
