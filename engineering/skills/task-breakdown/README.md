# task-breakdown — تقسيم المهام

## ما الذي تفعله المهارة
تقسّم الميزة إلى مهام صغيرة مرتبة، لكل مهمة معيار إنجاز قابل للفحص واعتماديات واضحة.

## متى تستخدمها
- عندك مواصفات وتريد خطة تنفيذ قابلة للتوزيع.
- مهمة تبدو ضخمة ويصعب تقدير حجمها.

## أمثلة على الطلبات
1. «قسّم ميزة تسجيل الدخول بحساب Google إلى مهام لسبرنت واحد.»
2. «هذه مواصفات لنظام إشعارات: [الصق المواصفات]. أريد تذاكر جاهزة للنسخ.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| المهام | جدول مهام بمعيار إنجاز واعتماديات لكل منها |
| التقدير | نسبي (صغير/متوسط/كبير) وموسوم كافتراض |
| المجهول | مهام Spike محدودة قبل الالتزام |
