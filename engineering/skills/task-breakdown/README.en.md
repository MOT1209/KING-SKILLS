# task-breakdown — task breakdown

> English translation of [README.md](README.md).

## What the skill does
Splits a feature into small ordered tasks, each with a checkable definition of done and clear dependencies.

## When to use it
- You have specifications and want an execution plan that can be distributed.
- A task looks huge and its size is hard to estimate.

## Example requests
1. "Split the Google sign-in feature into tasks for a single sprint."
2. "These are the specifications for a notification system: [paste specifications]. I want tickets ready to copy."

## What to expect
| Item | What you get |
|---|---|
| The tasks | A table with a definition of done and dependencies for each |
| Estimate | Relative (small/medium/large) and marked as an assumption |
| The unknown | Bounded Spike tasks before commitment |
