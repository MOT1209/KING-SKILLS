# feature-spec — مواصفات الميزة

## ما الذي تفعله المهارة
تحوّل فكرة ميزة إلى مواصفات واضحة: المشكلة، النطاق، معايير قبول قابلة للاختبار، حالات حافة، وأسئلة مفتوحة.

## متى تستخدمها
- عندك فكرة ميزة بلا تفاصيل وتريد وضوحاً قبل البناء.
- تريد معايير قبول يتفق عليها الفريق قبل التنفيذ.

## أمثلة على الطلبات
1. «اكتب مواصفات لميزة إعادة تعيين كلمة المرور عبر البريد في تطبيقنا.»
2. «عندي فكرة نظام إشعارات داخل التطبيق، حوّلها لمواصفات وحدّد ما ينقصني من قرارات.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| المواصفات | مشكلة ونطاق ومعايير قبول مرقمة قابلة للاختبار وحالات حافة |
| الناقص | أسئلة مفتوحة موسومة: تعطّل التنفيذ أو لا تعطّله |
| الحدود | لا حلول تقنية تفصيلية ولا أرقام مختلقة |
