# bug-reproduction — إعادة إنتاج الأخطاء

## ما الذي تفعله المهارة
تحوّل بلاغ خطأ إلى خطوات إعادة دقيقة بأقل مدخلات، واختبار فاشل يثبت الخطأ قبل الإصلاح.

## متى تستخدمها
- بلاغ خطأ غامض أو غير قابل للتكرار.
- تريد اختباراً يحمي من عودة الخطأ بعد إصلاحه.

## أمثلة على الطلبات
1. «المستخدمون يقولون إن البحث لا يعرض نتائج بالعربية أحياناً، أعد إنتاج الخطأ واكتب اختباراً يثبته.»
2. «هذا stack trace من الإنتاج: [الصق]. أريد خطوات إعادة وحالة اختبار.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الخطوات | مرقمة بالفعلي والمتوقع والحد الأدنى للمدخلات |
| الاختبار | يفشل لسبب الخطأ نفسه مع مخرجات تشغيل فعلية |
| إن تعذّرت الإعادة | ما جُرّب وما ينقص بدل ادعاء النجاح |
