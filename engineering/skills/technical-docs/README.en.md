# technical-docs — technical documentation

> English translation of [README.md](README.md).

## What the skill does
Writes technical documentation for a module or an API: an overview, a quick start, a reference with parameters and errors, and examples that were actually run.

## When to use it
- You are documenting a module, an API or an internal tool.
- Your documentation went stale after a code change.

## Example requests
1. "Document the `payments` module in `src/payments` with usage examples."
2. "Write a README for this project with a quick start that can be executed."

## What to expect
| Item | What you get |
|---|---|
| The file | An overview, a quick start, a reference with parameters and errors, examples |
| The examples | Actually run, and their outputs are real |
| Unconfirmed | Explicitly marked |
