# technical-docs — التوثيق التقني

## ما الذي تفعله المهارة
تكتب توثيقاً تقنياً لوحدة أو API: نظرة عامة، بدء سريع، مرجع بالمعاملات والأخطاء، وأمثلة نُفّذت فعلاً.

## متى تستخدمها
- توثّق وحدة أو API أو أداة داخلية.
- توثيقك تقادم بعد تغيير الكود.

## أمثلة على الطلبات
1. «وثّق وحدة `payments` في `src/payments` مع أمثلة استعمال.»
2. «اكتب README لهذا المشروع مع بدء سريع قابل للتنفيذ.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الملف | نظرة عامة، بدء سريع، مرجع بالمعاملات والأخطاء، أمثلة |
| الأمثلة | نُفّذت فعلاً ومخرجاتها حقيقية |
| غير المؤكد | يُوسم صراحة |
