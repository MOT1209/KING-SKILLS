# code-review — مراجعة الكود

## ما الذي تفعله المهارة
تراجع الكود الذي تقدّمه بحثاً عن الأخطاء المنطقية والثغرات الأمنية ومشكلات الأداء، وتشرح سبب كل ملاحظة وتقترح إصلاحاً واضحاً.

## متى تستخدمها
- قبل دمج طلب سحب (Pull Request).
- عند الشك في وجود خلل أو ثغرة في دالة أو ملف.
- لتحسين أداء جزء بطيء من الكود.

## أمثلة على الطلبات
1. «راجع هذه الدالة بحثاً عن الأخطاء والثغرات الأمنية: [الصق الكود]»
2. «راجع التغييرات في الفرع الحالي مقارنة بـ main وركّز على الأداء.»
3. «هذا الاستعلام يبطؤ مع زيادة البيانات: [الصق الكود]. ما السبب المحتمل وكيف أصلحه؟»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الملاحظات | مرتبة من الأشد إلى الأخف: الموقع، الخطورة، السبب، الإصلاح |
| التأكيد | ملاحظات مؤكدة فقط؛ غير المؤكد يُعلَّم «محتمل» |
| الملخص | عدد الملاحظات حسب الخطورة وتوصية بالدمج أو التعديل |
| الأمان | وصف الثغرة وإصلاحها دون شيفرات استغلال |
