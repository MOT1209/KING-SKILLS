# error-handling — معالجة الأخطاء

## ما الذي تفعله المهارة
تصمّم معالجة أخطاء متسقة: تصنيف، أكواد ثابتة، رسائل آمنة للمستخدم، تسجيلاً منظماً، وسياسة إعادة محاولة.

## متى تستخدمها
- تصمّم استراتيجية أخطاء لخدمة جديدة.
- تجد catch فارغاً أو أخطاء تتسرب للمستخدم.

## أمثلة على الطلبات
1. «راجع معالجة الأخطاء في خدمة الدفع وأخبرني أين تُبتلع الأخطاء أو تتسرب للمستخدم.»
2. «صمّم استراتيجية أخطاء موحدة لواجهة Express الخلفية مع وسيط مركزي.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| التصنيف | جدول: النوع، الكود، رمز الاستجابة، الرسالة، مستوى السجل |
| الكود | نموذج للطبقات مع سياق وسبب أصلي |
| الحدود | لا أسرار أو بيانات شخصية في السجلات |
