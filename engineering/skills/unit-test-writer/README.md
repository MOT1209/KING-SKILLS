# unit-test-writer — اختبارات الوحدة

## ما الذي تفعله المهارة
تكتب اختبارات وحدة بإطار مشروعك للحالات الطبيعية والحدّية والأخطاء، دون الارتباط بالتفاصيل الداخلية.

## متى تستخدمها
- تغطي دالة أو صنفاً جديداً أو غير مغطى.
- تحوّل خللاً مكتشفاً إلى اختبار انحدار.

## أمثلة على الطلبات
1. «اكتب اختبارات لهذه الدالة `calculateTax` بـ Jest: [الدالة]»
2. «ملف `cart.service.ts` بلا اختبارات، غطِّ سلوكه العام وحالاته الحدّية.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الاختبارات | ملف بإطار مشروعك: حالات طبيعية وحدّية وأخطاء |
| التحقق | تمر الآن وتفشل عند كسر المنطق عمداً |
| الحدود | لا بيانات حقيقية ولا تعديل للشيفرة المختبَرة دون إذنك |
