# architecture-decision — قرار معماري (ADR)

## ما الذي تفعله المهارة
تكتب قراراً معمارياً بصيغة ADR: السياق، الخيارات بمزاياها وعيوبها، القرار، والعواقب.

## متى تستخدمها
- تختار بين تقنيتين أو نمطين لهما أثر طويل.
- تريد تسجيل سبب قرار حتى لا يُنسى.

## أمثلة على الطلبات
1. «اكتب ADR لاختيار Redis أم قائمة رسائل لمهام الخلفية، سياقنا: [الوصف].»
2. «وثّق قرارنا بتقسيم التطبيق إلى خدمتين ولماذا رفضنا البقاء Monolith.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الملف | ADR بالسياق والخيارات والقرار والعواقب وحالة واضحة |
| العواقب | الإيجابية والسلبية معاً |
| الحدود | لا قياسات أو تكاليف مختلقة؛ الناقص يوسم [يُستكمل] |
