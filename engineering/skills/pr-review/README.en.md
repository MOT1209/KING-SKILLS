# pr-review — pull request review

> English translation of [README.md](README.md).

## What the skill does
Reviews the pull request and produces findings ordered by severity, separating mandatory from suggestion, with a final verdict on readiness.

## When to use it
- Before merging a Pull Request.
- You are writing organized review comments for a colleague.

## Example requests
1. "Review this PR: [link or diff]. I want what blocks the merge separate from the suggestions."
2. "Write review comments for this permissions system change in a respectful tone."

## What to expect
| Item | What you get |
|---|---|
| The verdict | Ready / ready after addressing the mandatory / needs work |
| The findings | Mandatory, important, suggestion, question; each with location, reason and fix |
| Limits | A recommendation, not a merge decision on your behalf; confirmed findings only |
