# pr-review — مراجعة طلب الدمج

## ما الذي تفعله المهارة
تراجع طلب الدمج وتخرج ملاحظات مرتبة حسب الخطورة، مع فصل الإلزامي عن الاقتراح، وحكم نهائي على الجاهزية.

## متى تستخدمها
- قبل دمج Pull Request.
- تكتب تعليقات مراجعة منظّمة لزميل.

## أمثلة على الطلبات
1. «راجع هذا الـ PR: [رابط أو diff]. أريد ما يمنع الدمج منفصلاً عن الاقتراحات.»
2. «اكتب تعليقات مراجعة لتغيير نظام الصلاحيات هذا بنبرة محترمة.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الحكم | جاهز / جاهز بعد معالجة الإلزامي / يحتاج عملاً |
| الملاحظات | إلزامي، مهم، اقتراح، سؤال؛ لكل منها الموقع والسبب والإصلاح |
| الحدود | توصية لا قرار دمج نيابةً عنك؛ ملاحظات مؤكدة فقط |
