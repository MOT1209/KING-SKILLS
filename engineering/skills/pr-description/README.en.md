# pr-description — pull request description

> English translation of [README.md](README.md).

## What the skill does
Writes a clear Pull Request description: why, what changed, how to test, and the risks and rollback plan.

## When to use it
- Before opening a Pull Request.
- Your current PR description is vague or incomplete.

## Example requests
1. "Write the PR description for these changes (the current branch against main)."
2. "Improve this PR description to be clearer for the reviewer: [current description]"

## What to expect
| Item | What you get |
|---|---|
| The description | Why, what changed, how to test, risks and rollback |
| The tests | Only what was actually run |
| Limits | The PR is not created unless you ask |
