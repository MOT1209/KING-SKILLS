# pr-description — وصف طلب الدمج

## ما الذي تفعله المهارة
تكتب وصف Pull Request واضحاً: لماذا، وما الذي تغيّر، وكيف يُختبر، وما المخاطر وخطة التراجع.

## متى تستخدمها
- قبل فتح Pull Request.
- وصف طلبك الحالي غامض أو ناقص.

## أمثلة على الطلبات
1. «اكتب وصف PR لهذه التغييرات (الفرع الحالي مقابل main).»
2. «حسّن وصف هذا الطلب ليكون أوضح للمراجع: [الوصف الحالي]»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الوصف | لماذا، ما تغيّر، كيف يُختبر، المخاطر والتراجع |
| الاختبارات | ما شُغّل فعلاً فقط |
| الحدود | لا يُنشأ الطلب إلا بطلبك |
