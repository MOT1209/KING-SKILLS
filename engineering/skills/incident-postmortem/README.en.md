# incident-postmortem — incident postmortem

> English translation of [README.md](README.md).

## What the skill does
Turns incident notes and logs into an organized report: a timeline, a root cause with contributing factors, and prevention actions, in blameless wording.

## When to use it
- An incident ended and you want an organized report.
- You have scattered notes and logs.

## Example requests
1. "Write the postmortem from these notes and logs: [paste]"
2. "Improve this report so it is free of blame and has actionable prevention actions."

## What to expect
| Item | What you get |
|---|---|
| The report | A summary, impact, timeline, root cause and contributing factors |
| The actions | Prevention with a role owner and a priority |
| Limits | No blaming individuals; what is unproven appears as an unresolved question |
