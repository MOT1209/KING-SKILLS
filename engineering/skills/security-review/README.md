# security-review — مراجعة أمنية

## ما الذي تفعله المهارة
تفحص الكود بحثاً عن الثغرات الشائعة (حقن، XSS، أسرار مكشوفة، صلاحيات ضعيفة) وتقترح إصلاحاً لكل نتيجة.

## متى تستخدمها
- قبل دمج أو إطلاق كود يعالج مدخلات خارجية أو مصادقة.
- تفحص مستودعاً بحثاً عن أسرار مكشوفة.

## أمثلة على الطلبات
1. «راجع هذه النقطة أمنياً قبل الدمج: [الكود]»
2. «ابحث في المستودع عن أسرار مكشوفة وأنماط حقن SQL.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| النتائج | مرتبة بالخطورة: الموقع، الفئة (OWASP/CWE)، الأثر، الإصلاح |
| الفحص | ما فُحص وما لم يُفحص صراحة |
| الحدود | كشف وإصلاح فقط: لا شيفرة استغلال ولا طباعة قيم الأسرار |
