# code-scaffold — هيكل وحدة جديدة

## ما الذي تفعله المهارة
تقرأ وحداتك الموجودة وتنشئ وحدة جديدة بالنمط نفسه: التسمية، تقسيم الملفات، التسجيل، واختبار أولي.

## متى تستخدمها
- تضيف وحدة أو خدمة أو مكوّناً جديداً إلى مشروع قائم.
- تريد التزاماً بأنماط مشروعك دون نسخ يدوي.

## أمثلة على الطلبات
1. «أنشئ مكوّن React جديداً اسمه `PaymentForm` على نمط بقية المكونات في `src/components`.»
2. «أضف خدمة `notifications` إلى المشروع بنفس هيكل خدمة `users`.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الملفات | هيكل بنمط مشروعك وتسجيل في الوحدة الأم |
| التحقق | اختبار أولي ونتيجة البناء والفحوصات |
| الحدود | لا منطق عمل مخمَّن ولا اعتماديات جديدة دون موافقتك |
