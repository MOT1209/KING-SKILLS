# data-analysis — data analysis

> English translation of [README.md](README.md).

## What the skill does
Reads the CSV or Excel file you attach, computes statistics, trends and comparisons in code, and then writes a short report in which every number was actually computed from your file.

## When to use it
- You have a sales, survey or log file and want to understand it quickly.
- You want to know the highest and lowest values and the trend over time.
- You want a report ready to share.

## Example requests
1. "I attached sales.csv. Analyze the monthly sales and tell me which products grew the most."
2. "This is an Excel file of customer satisfaction survey results. Summarize the results by age group and give me a one-page report."
3. "In the attached expenses file, how much did we spend on each category, and are there any duplicate expenses?"

## What to expect
| Item | What you get |
|---|---|
| Summary | 3–5 lines with the direct answer |
| Numbers | A table of key indicators, all computed from your file |
| Data quality | A warning about empty, duplicate and outlier values |
| Transparency | A list of what was excluded or changed during the analysis |
