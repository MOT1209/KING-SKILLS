# data-analysis — تحليل البيانات

## ما الذي تفعله المهارة
تقرأ ملف CSV أو Excel الذي ترفقه، وتحسب الإحصاءات والاتجاهات والمقارنات بالكود، ثم تكتب تقريراً مختصراً كل أرقامه محسوبة فعلاً من ملفك.

## متى تستخدمها
- عندك ملف مبيعات أو استبيان أو سجلات وتريد فهمه بسرعة.
- تريد معرفة أعلى القيم وأدناها والاتجاه عبر الزمن.
- تريد تقريراً جاهزاً للمشاركة.

## أمثلة على الطلبات
1. «أرفقت sales.csv. حلّل المبيعات الشهرية وأخبرني أي المنتجات الأعلى نمواً.»
2. «هذا ملف Excel لنتائج استبيان رضا العملاء. لخّص النتائج بحسب الفئة العمرية وأعطني تقريراً من صفحة واحدة.»
3. «في ملف المصروفات المرفق، كم أنفقنا على كل فئة، وهل هناك مصروفات مكررة؟»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الملخص | 3–5 أسطر بالإجابة المباشرة |
| الأرقام | جدول بأهم المؤشرات، كلها محسوبة من ملفك |
| جودة البيانات | تنبيه إلى الفارغ والمكرر والشاذ |
| الشفافية | قائمة بما استُبعد أو عُدِّل أثناء التحليل |
