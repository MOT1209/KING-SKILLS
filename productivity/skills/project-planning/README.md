# project-planning — تخطيط المشاريع

## ما الذي تفعله المهارة
تحوّل هدفك إلى خطة عملية: مراحل ومهام ومواعيد ومخاطر ومعايير نجاح.

## متى تستخدمها
- عندك فكرة أو هدف ولا تعرف من أين تبدأ.
- تريد جدولاً زمنياً واقعياً بمحطات واضحة.
- تريد توقّع المخاطر قبل أن تقع.

## أمثلة على الطلبات
1. «خطّط لإطلاق متجر إلكتروني صغير خلال 8 أسابيع، بفريق من ثلاثة أشخاص.»
2. «قسّم مشروع تنظيم ملتقى مهني ليوم واحد إلى مراحل ومهام، وحدّد المخاطر الرئيسة.»
3. «عندي أسبوعان لتسليم تقرير سنوي. رتّب لي المهام يوماً بيوم.»

## ماذا تتوقع
| العنصر | ما ستحصل عليه |
|---|---|
| الملخص | الهدف ومعايير النجاح وخارج النطاق |
| الخطة | جدول المراحل والمهام والمدد والاعتماديات |
| المخاطر | جدول بالاحتمال والأثر وخطة التخفيف |
| التقديرات | موسومة كافتراضات تعدّلها؛ لا ميزانيات مختلقة |
