# presentations — presentations

> English translation of [README.md](README.md).

## What the skill does
Builds you a presentation of 8 to 12 slides: a clear title for each slide, concise points, and speaker notes explaining what to say.

## When to use it
- You need a deck for a meeting, a lecture or a project pitch.
- You have a text or report and want to turn it into slides.

## Example requests
1. "Prepare a 10-slide presentation on cybersecurity basics for new employees, 15 minutes long."
2. "Turn this report into a presentation for management, focusing on the results and recommendations: [paste report]"
3. "I want an 8-slide deck to present my app idea to an investor, in a persuasive tone."

## What to expect
| Item | What you get |
|---|---|
| Slide count | Between 8 and 12 slides in a logical order |
| Each slide | A title, 3–5 points, speaker notes, and a suggested visual |
| The file | A presentation file if tools are available, otherwise organized content to copy |
| Missing information | Figures and sources not provided are marked [TBD] |
