# create-brand-kit

Run a structured, critique-driven brand-identity process and deliver a complete, packaged brand kit rather than a single logo file.

## What the skill does

- Starts from whatever exists: a website, a written brief, a product list, or just a name and a concept.
- Defines positioning, personality and visual direction, then reviews the direction against the brief.
- Designs a logomark, outlined wordmark and horizontal/vertical lockups.
- Produces round-safe icons, a self-theming favicon, PNG rasters and an icon set.
- Generates a guidelines page, a README for the kit and optional AI merch mockups.
- Checks small sizes, contrast and consistency before calling the kit finished.

## When to use

Use it when the user wants a logo, a brand, a visual identity, a rebrand, a logomark, brand assets, a favicon or icon set, or says "design a logo for my company", "we need branding", "make us a brand kit" or shares a company site asking for identity work.

Do not use it for a single social post graphic (use `social-graphics`) or for screen layout work (use `ui-layout`).

## Example requests

- "Design a brand kit for my coffee roastery; here is our site."
- "We need a logo, favicon and guidelines for a developer tool called Northwind."
- "Rebrand this product with a more premium identity."

## What to expect

| Output | Details |
|---|---|
| Brand direction | Positioning, personality and a reviewed visual concept |
| Logo system | Logomark, outlined wordmark, lockups and round-safe icons |
| Brand assets | SVG/PNG files, self-theming favicon and icon set |
| Guidelines | A generated guidelines page and a kit README |
| Optional extras | AI merch mockups such as shirts, caps and cards |

## Requirements

Node.js and Python 3 for the helper scripts. Image-generation access is optional and only used for mockups.
