# build-a-game

Take a one-line game idea to a finished, polished browser game through a ten-step pipeline proven on a complete 25-minute game.

## What the skill does

- Locks the story, core loop and scope before any code is written.
- Builds visual debugging first so every scene can be inspected without guessing.
- Chooses an art style and a small design system that keeps the game coherent.
- Optionally casts and integrates voices with lip sync.
- Builds a playable vertical slice with a small agent team, then runs a structured playtest.
- Expands to the full game, polishes feel, audio and UI, and deploys to a compatible host.
- Writes `docs/HANDOFF.md` so a fresh session can resume at any step.

## When to use

Use it when someone wants to make, design or build a video game, browser game, Three.js game, game prototype or vertical slice, or says "I have a game idea", "help me build a game", "continue my game" or "next step".

Do not use it for editing a game trailer or gameplay video; use `davinci-resolve-video-edit` or `arabic-shorts` instead.

## Example requests

- "I have a game idea about a lighthouse keeper — build it."
- "Continue my Three.js game and make the next vertical slice."
- "Prototype a cozy farming game I can play in the browser."

## What to expect

| Output | Details |
|---|---|
| Game plan | Story, loop, scope, art direction and design system |
| Playable build | Vertical slice first, then the full browser game |
| Quality evidence | Visual debugging, playtest notes and regression checks |
| Handoff | `docs/HANDOFF.md` plus deployment instructions |

## Requirements

Node.js and a modern browser. Three.js is the default for a new 3D browser game; an existing game is inspected and adapted to its engine. Voice and audio tooling are optional.
